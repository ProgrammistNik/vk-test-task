# 🎮 Steam Download Monitor

![Python](https://img.shields.io/badge/Python-3.9%2B-blue)


Консольный Python-скрипт для мониторинга загрузок в **Steam**.  
Работает в фоне, автоматически определяет путь установки лаунчера и выводит информацию о всех активных загрузках.

---

## 📌 Возможности

- 🔍 Автоматическое определение пути установки Steam (через реестр Windows)
- 📦 Отображение **всех активных загрузок**
- 🧠 Определение статуса каждой игры:
- 🚀 Вывод текущей скорости загрузки (если активна)
- ⏱ Обновление данных раз в 1 минуту
- 🛑 Ограничение времени мониторинга (по умолчанию — 5 минут)
- 📋 Читаемый табличный вывод в консоль

---
